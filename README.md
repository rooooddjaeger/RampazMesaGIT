## Instalación

### Desarrollo

```bash
git clone <URL_DEL_REPOSITORIO>
```

1. Abrir en Android Studio
2. Sincronizar dependencias
3. Ejecutar en emulador o dispositivo

---

### Instalación (Empresa)

1. Generar APK:

```bash
Build > Build APK(s)
```

2. Instalar en dispositivo autorizado
3. Habilitar fuentes desconocidas
